# TechHub

 Is a collaboration platform where developers can post projects they're
building, find people to work with, and discover projects looking for
contributors. Think of it as a lightweight "help wanted" board for personal
and open-source projects — sign in with GitHub, publish what you're working
on, and let others discover it, comment, and upvote.

## Features

- **GitHub OAuth login** — sign in with your GitHub account, no separate
  passwords or accounts to manage
- **Project listings** — publish a project with a title, overview, and tech
  stack; browse everyone else's in a searchable feed
- **Status tracking** — project owners can mark their listing as *Open* or
  *Filled* once they've found collaborators
- **Comments** — ask questions or express interest directly on a project;
  authors can manage their own comments
- **Upvotes** — surface the most interesting projects through community
  upvotes
- **Profiles** — a personal profile with bio, skills, and links to your
  website, GitHub, and LinkedIn
- **API Explorer** — a built-in diagnostic dashboard for calling every backend
  endpoint directly and inspecting the live JSON response, useful for
  debugging and demoing the API during development
